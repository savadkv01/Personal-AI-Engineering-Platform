## Finish setup (once per machine)

1. Start the shared backend: `docker compose -f __PAIEP_HOME__/docker/docker-compose.yml --profile mcp up -d gateway qdrant postgres`
   and pull the autocomplete model: `docker exec paiep_ollama ollama pull {{ cookiecutter.autocomplete_model }}`.
2. Continue: `cp .continue/.env.example .continue/.env` and set `PAIEP_GATEWAY_TOKEN` (= `GATEWAY_TOKEN` in `__PAIEP_HOME__/docker/.env`).
3. Cline: *MCP Servers → Configure → Configure MCP Servers*, merge `.paiep/cline_mcp_settings.json`; set the API
   provider to **OpenAI Compatible**, base URL `{{ cookiecutter.gateway_url }}`, model `{{ cookiecutter.chat_model }}`, key = gateway token.
4. Verify: `python __PAIEP_HOME__/scripts/mcp-smoke.py --workspace __PAIEP_WORKSPACE__ --scope {{ cookiecutter.memory_scope }}`.
